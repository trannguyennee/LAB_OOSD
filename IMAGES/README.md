# IMAGES – Hình vẽ phân tích & thiết kế các LAB (OOSD)

Toàn bộ sơ đồ phân tích – thiết kế được vẽ bằng **draw.io (diagrams.net)** và lưu dưới dạng file nguồn `.drawio`.
Mở bằng draw.io Desktop hoặc <https://app.diagrams.net> → *Open Existing Diagram*. File có nhiều trang thì chuyển trang bằng các tab ở cạnh dưới.

| Thư mục | Nội dung |
|---|---|
| `LAB0/` | Cài đặt và kiểm tra môi trường – 6 ảnh chụp màn hình minh chứng JDK, Maven, Git, PlantUML, IntelliJ (Lab không có sơ đồ UML) |
| `LAB1/` | Bài 1 – Use Case hệ thống Thư viện trực tuyến; Bài 2 – Cửa hàng Nước giải khát: Use Case tổng quát, Class Diagram thiết kế, Use Case phân rã, Activity, Sequence |
| `LAB2/` | Hệ thống Quản lý Thư viện – 14 Activity Diagram và 14 Sequence Diagram (UC01–UC14) |
| `LAB3/` | Hệ thống Quản lý Khách sạn – 15 ảnh giao diện WinForms khi chạy chương trình (sơ đồ UML của bài nằm trong tài liệu đề Bài 3) |
| `LAB4/` | Hệ thống e-SHOPPING – Use Case tổng quát, Use Case đặt hàng & thanh toán, Class, Activity, Sequence |
| `LAB5/` | Công ty Du lịch Văn Hóa Việt – Class (2 trang: phân tích, thiết kế), Use Case, Use Case phân rã, Activity, Sequence |
| `LAB6/` | Quản lý hồ sơ bệnh án – Class (2 trang), Use Case, Use Case phân rã (4 trang), Activity, Sequence |
| `LAB7/` | Quản lý nhân sự Sơn Đông Á – Class (2 trang), Use Case, Use Case phân rã (4 trang), Activity, Sequence |
| `LAB8/` | Cửa hàng Nước giải khát (hiện thực của LAB1 Bài 2) – 5 sơ đồ, thuộc tính lớp khớp CSDL `QuanLyCuaHangNGK` |
